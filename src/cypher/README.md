# Cypher Module

This module handles Neo4j database interactions for the application.

## Directory Structure

- `core/`: Core connection and configuration files
- `conversion/`: Data conversion utilities
- `session/`: Session management
- `queries/`: Query building and execution
- `operations/`: Database operations (get, mutate)
    - `get/`: Read operations
    - `mutate/`: Write operations
- `client/`: Server API calls accessible from client
- `types/`: TypeScript type definitions
